# Project documentation

Documents for the Shree Balaji website and the Shop Manager billing software.

| Document | For | What it covers |
|----------|-----|----------------|
| [Sprint plan](SPRINT-PLAN.md) | Customer and developer | 5 one-week sprints: user stories, acceptance criteria, day-by-day plan, tests, demo scripts, go-live checklist, sign-off |
| [Architecture and system design](ARCHITECTURE.md) | Developer | Components, deployment on the shop PC, data model, billing, GST and publish flows, data protection design, key decisions |
| [Security](SECURITY.md) | Developer and owner | Threat model, login and roles, input safety, audit, secrets, PC hardening, website security, dependency checks |
| [Scalability and performance](SCALABILITY.md) | Developer | Expected load, performance targets, indexes, growth path to more PCs or branches, reliability |
| [Coding standards](CODING-STANDARDS.md) | Developer | TypeScript and Next.js rules, money and GST rules, transactions, validation, testing, Git workflow, CI |

Pricing and commercial terms are kept in the separate proposal document, not in this repository.
